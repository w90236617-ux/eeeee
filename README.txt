Open index.html in a browser, or upload this whole folder to Netlify (drag and drop).
Files: index.html, style.css, script.js, assets/ (profile, cv, certificate, project-images).
To add real project screenshots: put images in assets/project-images/ and follow the
comment above each card's .mock block in index.html.
Contact form: no email backend is configured, so it opens the visitor's email app (mailto) instead of
claiming the message was sent. For direct delivery, connect a service such as Formspree or EmailJS.
